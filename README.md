# SIH 2026 – Real-time Airfare Price Index for India

## Problem Statement

**Problem Statement ID:** 26056

**Organization:** Ministry of Statistics and Programme Implementation (MoSPI)

**Department:** Data Informatics & Innovation Division (DIID)

## Project Overview

This project aims to develop a real-time airfare price index for India
using automated data collection from airline and online travel
aggregator portals.

## Objectives

- Collect airfare data automatically
- Clean and normalize fare information
- Generate route-wise airfare indices
- Track changes in airfare prices
- Provide data visualization through a dashboard
- Support augmentation of the Consumer Price Index (CPI)
